Runtime and safety notes: This playground uses the pinned Pyodide 314.0.8 WebAssembly runtime in a module Web Worker. The worker can be terminated to stop a running program; doing so restarts the runtime for the next run. A 10-second execution watchdog is applied. The Python virtual filesystem is in-memory and does not grant direct access to your device's files. This is not a hardened security boundary: browser-side Python code may still access capabilities exposed by the runtime, and browser memory is not capped by this page. Do not run code you do not trust or enter passwords, API keys or private data. Only standard-library examples are included; external package installation is not enabled.
