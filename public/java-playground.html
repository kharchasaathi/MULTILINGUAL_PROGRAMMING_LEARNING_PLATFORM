Execution and privacy: This first version uses the independent Wandbox compile API. Your Java source and stdin are sent to Wandbox for compilation and execution; they are not run on the CodeSaathi website server. Do not paste passwords, API keys, personal data or confidential code. Availability, compiler versions, request limits and execution time are controlled by the provider. This is not the same environment as the course's Temurin JDK 21 CI validation.
Learning tip: For this hosted runner, use class Main (without public) because the provider compiles a fixed prog.java file. In your own IDE, use public class Main in Main.java. Use the input box for values read by Scanner. Read compiler errors before checking the program output.
