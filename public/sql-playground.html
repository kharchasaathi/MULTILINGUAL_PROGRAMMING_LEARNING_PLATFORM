Runtime, storage and safety: This playground uses sql.js 1.16.0 (SQLite compiled to WebAssembly) inside a dedicated browser Worker. Query execution does not connect to a remote database and learner SQL is not uploaded. A database snapshot is stored in IndexedDB on this browser; it is not automatically synced across devices. Reset removes the local database. Export downloads a SQLite database file. SQL statements are not arbitrary JavaScript, but this is an educational sandbox rather than a hardened multi-tenant security boundary. Do not enter secrets or private records. The runtime implements SQLite, not MySQL or SQL Server; commands such as CREATE DATABASE and USE are not supported by SQLite.
