Safe query patterns

Never build SQL by concatenating untrusted user input. Bind values through a prepared statement.

-- SQLite-style positional parameter
SELECT customer_id, customer_name
FROM customers
WHERE email = ?;

Bind the email value separately. Keep database credentials on a trusted server; never put passwords or privileged connection strings in browser JavaScript.

Before running UPDATE or DELETE, test the same condition with a SELECT. Use a transaction when several changes must succeed together.
