# B8 — Intermediate Level Curriculum

**Status:** Defined  
**Source policy:** W3Schools only  
**Depends on:** B7 Beginner Level  
**Artifacts:** `docs/B8_INTERMEDIATE_LEVEL_CURRICULUM.md`, `docs/B8_INTERMEDIATE_LEVEL_MAP.csv`

## 1. Purpose

Intermediate learning begins after a learner can write and explain basic HTML/CSS, use variables, conditions, loops and functions in one selected programming language, and understand basic SQL queries. This level moves from isolated syntax exercises to connected, stateful, multi-file work.

This is a level definition and source-linked topic map. It is not a claim that every W3Schools chapter has been copied or that every optional track is fully mapped.

## 2. Entry conditions

A learner should be able to:
- Build a basic multi-section HTML page and apply CSS.
- Use variables, data types, operators, conditions, loops and functions in their chosen first programming language.
- Read and write simple SQL statements.
- Use the relevant beginner track's examples and exercises without relying on answer copying.

A learner missing one of these foundations should return to the corresponding B7 module before continuing.

## 3. Learning outcomes

By the end of B8, learners should be able to:
1. Organize a responsive web interface using semantic HTML and structured CSS layout.
2. Add browser interaction through DOM selection, events, forms and browser-side data handling.
3. Write reusable program logic using collections, functions, modules and structured error handling in the chosen language.
4. Read and write structured JSON data and use the relevant W3Schools API/network topics where included in the chosen path.
5. Design relational table structures and write multi-table, grouped and conditional SQL queries.
6. Build, test and explain a small integrated application or data task using only concepts in the selected W3Schools track.

## 4. Common web pathway

### 4.1 HTML — intermediate scope
- Semantic HTML and page structure
- Forms: form elements, input types, attributes and validation-related attributes
- Media: audio, video and embedded content
- SVG and Canvas as optional visual tracks
- Browser APIs listed in the W3Schools HTML navigation: Web Storage, Drag and Drop, Geolocation, Web Workers and Server-Sent Events

### 4.2 CSS — intermediate scope
- Selectors, combinators, attribute selectors, pseudo-classes and pseudo-elements
- Specificity, inheritance and CSS variables
- Display, positioning, overflow, opacity and z-index
- Navigation bars, dropdowns, image galleries and form styling
- Flexbox and Grid
- Transforms, transitions and animations
- Responsive Web Design and responsive layouts

### 4.3 JavaScript — intermediate scope
- Functions and objects in practical combinations
- Arrays and array methods; Sets and Maps
- Scope, strict mode, error handling and debugging
- DOM access and manipulation
- Events and form validation/handling
- JSON
- Browser storage and cookies
- Asynchronous JavaScript, Promises and Fetch
- AJAX and JavaScript modules

Use the relevant W3Schools tutorial navigation as the topic boundary. Do not introduce browser or language APIs that are absent from the W3Schools source map.

## 5. Programming-language pathways

A learner selects one primary language pathway. These are not requirements to study every language.

### Python
- Functions: arguments, *args/**kwargs, scope, decorators, lambda, recursion and generators
- Iterators and modules
- JSON and RegEx
- PIP and virtual environments
- Try...Except
- File Handling
- Classes/Objects, __init__, properties and methods
- Inheritance, polymorphism and encapsulation
- Magic methods listed in the W3Schools Python tutorial

### Java, C, C++, C#, PHP and other W3Schools language tracks
Continue only with the topics listed in the corresponding W3Schools tutorial navigation and reference catalogue. B8 map includes entry links for these optional tracks; it does not assert exhaustive chapter extraction. Keep the same intermediate standard: reusable functions/methods, structured data, modular organization, object-oriented topics where the tutorial provides them, and practical exercises.

## 6. SQL pathway

- Joins: INNER, LEFT, RIGHT, FULL and SELF
- UNION and UNION ALL
- GROUP BY and HAVING
- EXISTS, ANY and ALL
- CASE and NULL functions
- Subquery concepts where present in the W3Schools SQL learning outcomes
- Database and table management: CREATE, ALTER and DROP
- Constraints and key relationships
- Indexes and Views
- Stored Procedures
- Parameters and Prepared Statements; SQL Injection awareness

The SQL path must emphasize combining related tables, grouping records, defining constraints and querying data safely. SQL dialect-specific material is limited to W3Schools' own pages and references.

## 7. Framework and specialist extensions

After the relevant core path, learners may choose W3Schools-listed extensions such as Bootstrap, React, jQuery, Vue, Angular, Node.js, Django, MySQL, PostgreSQL or MongoDB. These are optional, track-specific extensions—not universal prerequisites and not a substitute for core HTML/CSS/JavaScript, language or SQL foundations.

## 8. Practice and assessment

For each selected module:
- Read the corresponding W3Schools topic page.
- Work through the available W3Schools examples/Tryit surface.
- Complete the corresponding W3Schools exercises when available.
- Recreate the concept independently with changed names/data/content.
- Explain the result and identify at least one likely failure case.

Assessment should measure understanding and independent construction. Do not reproduce W3Schools exercise prompts, answers, lesson prose or code verbatim in platform content.

## 9. Intermediate completion criteria

A learner completes B8 when they can:
- Finish the selected common web modules required by their chosen route.
- Complete one primary programming-language pathway's intermediate modules.
- Complete the SQL intermediate modules if their chosen route uses databases.
- Build one small integrated project or data solution without copying a finished answer.
- Explain the structure, data flow and key decisions in their own words.
- Complete the mapped practice links and correct errors independently.

## 10. Boundaries and handoff

B8 does not include professional deployment, production operations, system architecture, advanced security engineering or platform-specific certification. Those belong to later levels/workstreams.

B8 is complete at **intermediate-level scope and track-map definition** only. The map is a curated learning sequence based on the existing W3Schools catalogue and captured topic inventory; it does not upgrade the completeness of B3/B4 inventories. Next curriculum task: B9 — Define Advanced Level.
