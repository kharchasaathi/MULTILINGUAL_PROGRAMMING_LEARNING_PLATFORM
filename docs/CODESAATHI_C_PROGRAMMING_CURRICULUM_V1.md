## Scope

This roadmap maps the current W3Schools C Tutorial navigation and its visible learning areas, including the expanded problem-solving and DSA sections. It covers tutorial topics, examples, exercises, quiz/challenges, projects and the listed standard-library reference families. It is a coverage plan, not a claim that every lesson is already written or released.

## Required learning assets

Each lesson must include: learning objectives; a detailed conceptual explanation; worked examples with expected behaviour; guided and independent tasks; hints; assessment questions with explanations; edge cases and common errors; and a clear statement of whether the example can be run in the available environment.

## C execution environment

The existing CodeSaathi browser playground runs HTML/CSS/JavaScript in an isolated browser iframe. It does **not** compile native C. C examples must not be shown as runnable in that playground. A safe C playground requires a separate compiler runtime (preferably isolated server-side compilation with strict resource limits and no secrets); until that exists, C lessons use compiler-based practice instructions and non-runnable code examples.

## Release gates

A topic is not released merely because it appears in the index. It must pass content review, technical correctness review, compiler validation where feasible, assessment review, accessibility review and language review for each published translation.
