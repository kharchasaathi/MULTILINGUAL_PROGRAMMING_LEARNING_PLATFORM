# B7 — Beginner Level Definition

**Status:** Complete — beginner-level scope and sequence documented  
**Source boundary:** W3Schools only  
**Branch:** `docs/project-foundation`  
**Depends on:** B6 — Master Topic Checklist  
**Next:** B8 — Define Intermediate Level

## 1. Purpose

Define the entry-level learning band for a learner with no assumed programming experience. Beginner lessons introduce concepts in a controlled order, use short examples, and provide frequent practice. The beginner band is a learning-level classification, not a separate list of technologies.

## 2. Source-led learning order

W3Schools' **Where To Start** guidance gives the web-development sequence as HTML → CSS → JavaScript. This is the default beginner web pathway:

1. HTML — create and structure a first web page.
2. CSS — style and lay out the page.
3. JavaScript — add interaction and dynamic behaviour.

The wider W3Schools tutorial catalogue also contains beginner-entry tutorials for Python, SQL, Java, C, C++, C#, PHP and other subjects. These are separate beginner tracks, not prerequisites for the HTML → CSS → JavaScript web pathway.

## 3. Beginner learning outcomes

By the end of the beginner band, a learner should be able to:

- Explain the role of a language or technology using the W3Schools tutorial's introductory scope.
- Read, write, and modify small examples in the selected track.
- Recognize the basic syntax and vocabulary introduced in the beginner sequence.
- Use variables, values, expressions, conditions, repetition, and functions where those concepts belong to the selected language's introductory tutorial.
- Build a small, self-contained outcome using only concepts already introduced.
- Use the relevant W3Schools Tryit/example and exercise links to practise and self-check.
- Identify an error message or incorrect output and make a simple correction.

These are platform learning outcomes written for this project; they are not copied W3Schools lesson text.

## 4. Beginner curriculum structure

### B7-01 — Orientation and learning tools
- What the selected tutorial teaches and where it sits in the W3Schools catalogue.
- Navigate the tutorial chapters.
- Read a small example, edit it, run it where the W3Schools editor supports it, and observe the result.
- Complete the introductory exercise before moving forward.

### B7-02 — Web foundation pathway (default)
**Sequence: HTML → CSS → JavaScript**

**HTML foundation**
- Introduction, editors, basic document, elements, attributes.
- Headings, paragraphs, styles, formatting, quotations, comments.
- Links, images, tables, lists, block/inline, div, classes, IDs, buttons.
- File paths, head, page title, basic layout and responsive introduction.
- Forms: form elements, input types, and introductory attributes.
- Semantic HTML and introductory media topics where included in the source sequence.

**CSS foundation**
- Introduction, syntax, selectors, adding CSS, comments.
- Colors, backgrounds, borders, margins, padding, box model.
- Text, fonts, links, lists, tables, display and visibility.
- Basic positioning and layout concepts.
- Introductory responsive design.

**JavaScript foundation**
- Introduction, placement, output, syntax, statements, comments.
- Variables and basic data types.
- Operators and expressions.
- Conditions and decision-making.
- Loops and repetition.
- Strings, numbers, arrays, objects, and functions at introductory level.
- Basic events and simple page interaction after HTML/CSS foundations.

### B7-03 — Programming-language beginner tracks
A learner may choose one W3Schools tutorial track as a first programming-language path. Do not require all tracks to be completed before the learner can progress.

- Python: introduction, setup, syntax, output, comments, variables, data types, operators, conditions, loops, collections, functions.
- Java: introduction, setup, syntax, output, variables, types, operators, conditions, loops, arrays, methods.
- C: introduction, setup, syntax, output, variables, data types, operators, conditions, loops, arrays and introductory functions.
- C++: introduction, setup, syntax, output, variables, types, operators, strings, conditions, loops and arrays.
- C#: introduction, setup, syntax, output, variables, types, operators, conditions, loops, arrays and methods.
- PHP: introduction, setup, syntax, comments, output, variables, data types, strings, operators, conditions, loops, arrays and functions.
- SQL: introduction, SELECT, filtering, sorting, inserting, updating, deleting, aggregate functions, grouping and basic joins.

The topic names above are a beginner-scope selection from the existing B3 W3Schools topic inventory. They are not a claim that every chapter of each tutorial belongs in the beginner band.

### B7-04 — Introductory data and supporting topics
Only introduce a supporting W3Schools subject when it directly supports the learner's selected track. Examples include JSON as a data format and MySQL as a database path. Do not require AI, cloud, data-science, framework, or specialist tracks as universal beginner prerequisites.

## 5. Beginner boundaries

Keep these for later learning levels unless a W3Schools beginner chapter explicitly introduces the concept as a basic prerequisite:

- Advanced language features and deep API/reference catalogues.
- Complex algorithms and advanced DSA problem solving.
- Advanced object-oriented design, architecture, and design patterns.
- Complex asynchronous programming and advanced browser/runtime APIs.
- Framework-heavy application development.
- Advanced database administration, optimization, and dialect-specific details.
- Production deployment, security engineering, and professional operations.

This boundary is a level-placement decision for this platform; it does not remove those subjects from the overall W3Schools-derived curriculum.

## 6. Teaching and practice rules

- Teach one new concept at a time.
- Introduce terminology before using it in a task.
- Start with a short worked example; then ask the learner to change one part and predict the result.
- Follow with a small exercise, then a short coding challenge where the source tutorial provides one.
- Reuse W3Schools examples/exercise destinations as source links; create original platform explanations, tasks, hints, solutions, and diagrams.
- Do not copy W3Schools lesson paragraphs, code examples, exercise prompts, answers, or diagrams.
- Keep the six platform languages (Telugu, English, Malayalam, Kannada, Tamil, Hindi) as presentation/localization variants of the same learning objectives; do not change the technical scope by language.

## 7. Beginner completion criteria

A learner completes a selected beginner track when they can:

1. Navigate the track and explain its purpose.
2. Complete the beginner topic sequence assigned to that track.
3. Read and modify introductory examples.
4. Complete the mapped beginner exercises with the platform's configured mastery threshold.
5. Produce one small independent outcome using only beginner concepts.
6. Explain the main concepts used in that outcome.

The platform should record completion per track. Completing the web pathway does not automatically mark Python, Java, SQL, or other tracks complete.

## 8. Progression to B8

B8 should define how learners move from beginner concepts to combined concepts, larger programs, more complex data handling, structured problem solving, and deeper use of the selected W3Schools tutorial. B8 must use the same track-specific mapping model and must not assume that every learner follows every language.
