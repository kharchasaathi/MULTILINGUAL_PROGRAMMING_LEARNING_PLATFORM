# B9 — Advanced Level Curriculum

**Status:** Defined  
**Exclusive curriculum source:** W3Schools  
**Depends on:** B7 Beginner and B8 Intermediate  
**Artifacts:** `docs/B9_ADVANCED_LEVEL_CURRICULUM.md`, `docs/B9_ADVANCED_LEVEL_MAP.csv`

## 1. Purpose

B9 advances learners from building connected intermediate applications to solving complex programming and data problems, selecting suitable data structures and algorithms, reasoning about performance, and combining advanced topics from a chosen W3Schools track.

This document defines an advanced-level pathway and source-linked map. It does not claim every W3Schools tutorial sidebar or reference member has been exhaustively captured.

## 2. Entry requirements

Learners should have completed the relevant B8 path and be able to:
- Build a responsive page with structured HTML/CSS and interactive JavaScript.
- Use functions, objects, collections, modules and error handling in a primary programming language.
- Work with JSON and the relevant asynchronous/browser topics in their selected path.
- Write multi-table SQL queries and understand relational constraints.
- Read, modify and explain a small application or data solution.

## 3. Advanced learning outcomes

By the end of B9, learners should be able to:
1. Select and implement suitable data structures for a problem.
2. Implement and compare searching, sorting, traversal and graph algorithms.
3. Explain time-complexity trade-offs at the level covered by W3Schools DSA.
4. Use advanced language constructs such as classes, inheritance, modules and asynchronous programming where the selected W3Schools track provides them.
5. Combine browser, data and programming concepts into a larger independent project.
6. Analyze and improve a solution using test cases, measured behavior and clear reasoning.

## 4. Core advanced pathway — DSA

DSA is the principal cross-language advanced pathway. W3Schools presents DSA as a tutorial with lessons, exercises and quizzes, and identifies basic programming knowledge in Python, C, C++, Java or JavaScript as prior knowledge.

### 4.1 Data structures
- Arrays and linked lists
- Linked-list memory, types and operations
- Stacks and queues
- Hash tables, hash sets and hash maps
- Trees and binary trees
- Tree traversal: pre-order, in-order and post-order
- Binary search trees and AVL trees
- Graphs, graph implementation and traversal
- Cycle detection

### 4.2 Algorithms
- Bubble, selection, insertion, quick, counting, radix and merge sort
- Linear and binary search
- Shortest path
- Dijkstra's and Bellman-Ford
- Minimum spanning tree
- Prim's and Kruskal's
- Maximum flow
- Ford-Fulkerson and Edmonds-Karp

### 4.3 Complexity
- Time complexity introduction
- Time complexity for sorting and searching algorithms
- Compare algorithm behavior and select a suitable approach for the problem

Use the W3Schools DSA syllabus and tutorial module list as the exact scope boundary. Do not introduce additional algorithms merely because they are common in other curricula.

## 5. Advanced JavaScript pathway

Use the W3Schools JavaScript study plan and tutorial navigation for:
- Objects and classes
- Modules
- Asynchronous JavaScript
- HTML DOM and Browser DOM
- Web APIs
- AJAX and JSON
- Graphics topics where selected by the learner
- Errors, debugging and coding best practices
- JavaScript versions and language features shown in the tutorial

The W3Schools study plan places classes, modules, async, DOM, Web APIs, AJAX and JSON after core language foundations. B9 treats these as advanced combinations, not beginner prerequisites.

## 6. Advanced Python pathway

Use W3Schools Python and DSA with Python:
- Advanced use of functions, iterators and generators where relevant to the track
- Classes and object-oriented programming topics from the Python tutorial
- DSA implementation using Python
- Lists/arrays, stacks, queues, linked lists, hash tables, trees and graphs
- Searching and sorting algorithms
- Time complexity

The DSA concepts remain language-independent; Python is one implementation route, not a requirement for all learners.

## 7. Advanced SQL and data pathway

Continue from B8 using W3Schools SQL topics and reference pages:
- Complex multi-table query composition using joins and set operations
- Grouped and conditional query patterns
- Subqueries and advanced query constructs only where present in W3Schools SQL topics
- Views, indexes, stored procedures, parameters and prepared statements
- Database structure and constraints applied to a larger data task

Database-specific tracks such as MySQL, PostgreSQL and MongoDB remain optional W3Schools-listed extensions. Keep dialect-specific features within the corresponding W3Schools tutorial/reference.

## 8. Optional advanced subject tracks

Learners may choose an advanced extension from W3Schools' tutorial catalogue after completing its relevant prerequisites:
- TypeScript, Node.js, React, Angular, Vue, Django and other listed framework tracks
- Data Science, NumPy, Pandas, SciPy, Matplotlib and Statistics
- AI, Generative AI and Machine Learning
- Cyber Security and AWS Cloud
- Git and Bash

These are independent elective pathways. Their inclusion in the catalogue does not mean every learner must study them or that their full advanced chapter maps are complete in B9.

## 9. Advanced practice model

For each selected topic:
1. Study the corresponding W3Schools lesson and reference material.
2. Work through its available examples and exercises.
3. Implement the concept independently with changed inputs and requirements.
4. Compare at least two valid approaches when the topic supports comparison.
5. Explain data flow, algorithm choice and complexity where applicable.
6. Record edge cases and test the implementation against them.

Platform lessons and exercises must be original. Do not copy W3Schools lesson prose, exercise prompts, answers or code examples verbatim.

## 10. Advanced capstone expectations

Complete one substantial capstone selected from the learner's pathway:
- DSA problem-solving portfolio with implementations and complexity explanations; or
- Interactive web application using advanced JavaScript, DOM, modules and asynchronous topics; or
- Python application combining object-oriented design, structured data and selected DSA; or
- Data/database solution using advanced SQL and a chosen W3Schools database track.

The learner must submit source code, a short architecture/algorithm explanation, test cases, and a demonstration of expected behavior. The capstone is an assessment format, not an additional technology syllabus.

## 11. Completion criteria

B9 is complete for a learner when they:
- Complete the selected advanced core modules.
- Implement and explain the relevant DSA structures/algorithms, including complexity topics, if following the DSA route.
- Demonstrate advanced language topics in their chosen language path.
- Complete a capstone independently and explain key decisions.
- Work through the mapped W3Schools practice links where available.

## 12. Boundaries and handoff

B9 does not define professional-level production operations, large-scale system architecture, organization-wide engineering practices or professional role specializations. These belong to B10 and later project workstreams.

B9 is complete at **advanced-level scope and track-map definition**. The DSA path has a detailed source-linked topic sequence; optional language/framework/data tracks remain bounded by their W3Schools tutorial navigation and are not represented as exhaustively mapped. Existing B3/B4 inventory limitations remain unchanged.
