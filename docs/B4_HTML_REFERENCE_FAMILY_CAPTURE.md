## 4. Boundary and counting rules

- The 19 rows above are reference families/navigation entries captured from the W3Schools HTML reference navigation, not 19 independent programming courses.
- HTML by Alphabet and HTML by Category are alternate groupings of the same element family; do not count their members twice.
- HTML Colors, Canvas, Character Sets, and Audio/Video may also appear in other W3Schools reference groups. Preserve parent-child relationships to prevent duplicate counting.
- A family URL is not proof that every member has been extracted. Member-level extraction and row-level source mapping remain pending.
- This capture does not claim complete HTML member coverage and does not close B4.
