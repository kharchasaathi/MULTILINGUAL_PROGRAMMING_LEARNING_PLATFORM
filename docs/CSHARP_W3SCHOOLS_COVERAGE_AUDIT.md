## Advanced supplemental coverage

W3Schools is the coverage baseline, not the ceiling. Microsoft Learn's current C# guide adds essential professional topics: type system, pattern matching, LINQ, asynchronous programming, reflection/attributes, expression trees, native interoperability, performance engineering and Roslyn. These are planned in CSH13–CSH20 as supplemental material, with version compatibility explicitly documented.

## Technical version policy

- Initial reproducible baseline: .NET 10 LTS / C# 14.
- .NET 11 / C# 15 is current STS as of 2026-11-25. Keep preview/current STS-specific features in a clearly marked compatibility module; do not require them for the LTS core lessons.
- CI must install a pinned .NET 10 SDK and report exact `dotnet --info`.
- Validate every runnable example by compiling and executing with isolated temporary projects. JSON/schema validation alone is not technical validation.
