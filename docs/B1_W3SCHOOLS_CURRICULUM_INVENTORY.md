# B1 — W3Schools Curriculum Category Inventory

**Status:** Completed as a category-level baseline  
**Inventory date:** 2026-11-04  
**Reference:** W3Schools official tutorial catalogue and official references/exercises catalogue  
**Scope:** B1 only — category and catalogue-area discovery. Detailed chapter/topic enumeration belongs to B3 and B4; exercises/examples mapping belongs to B5.

## 1. Method and interpretation

The W3Schools catalogue is a changing catalogue rather than a fixed, formally numbered syllabus. The official Tutorials page exposes a broad catalogue of learning subjects, while the References and Exercises areas expose additional reference and practice collections. For this inventory, subjects have been grouped into 15 curriculum families for our own planning. These family names are our classification, not claims that W3Schools itself publishes exactly these 15 headings.

Primary sources:
- https://www.w3schools.com/ — official W3Schools catalogue and navigation.
- https://www.w3schools.com/ — official References and Exercises sections (visible through the catalogue/navigation).
- Search-indexed official catalogue snapshot consulted on 2026-11-04: https://www.w3schools.com/?trk=public_post_comment-text
- Official catalogue snapshot with references/exercises: https://www.w3schools.com/?LanguageId=1

## 3. Additional catalogue sections to track separately

These are important W3Schools learning/reference/practice areas, but should not be counted as additional programming languages or duplicate tutorial subjects:

- **References:** language and technology references such as HTML, CSS, JavaScript, SQL, Python, Java, C, C++, PHP, MySQL, W3.CSS, Bootstrap, Node.js, Django, jQuery, Vue, Angular, Sass, XML, JSON, ASP, Icons, SVG, Canvas, character sets, emojis, AppML, and W3.JS.
- **Exercises:** topic-linked practice collections for HTML, CSS, JavaScript, SQL, Python, Java, C, C++, C#, PHP, React, MySQL, Excel, DSA, Bootstrap versions, Node.js, TypeScript, Django, PostgreSQL, jQuery, NumPy, Pandas, Angular, Git, MongoDB, R, Go, Kotlin, Swift, Vue, SciPy, Bash, and other catalogue subjects as currently offered.
- **Quizzes, challenges, practice problems and certificates:** assessment and credential surfaces. These will be inventoried in B5 and later assessment design, not treated as programming-language categories.
- **How To, examples, code editor, Spaces and templates:** practical learning resources or tools; map them to relevant topics rather than treating each as a separate language.

## 4. Relevance and scope controls

### Core curriculum candidates
HTML, CSS, JavaScript, introductory programming, Python, Java, C, C++, C#, PHP, SQL, databases, DSA, Git, TypeScript, Node.js, web frameworks, data formats, AI/ML, data science, cloud fundamentals, cybersecurity, accessibility, and responsive web design.

### Supporting or specialization candidates
Excel/Google Sheets, Raspberry Pi, graphics APIs, scientific Python libraries, cloud-provider-specific material, and selected productivity tools. Their inclusion and depth will be decided through B2/B3 and target-student outcomes.

### Legacy or time-sensitive catalogue entries
Catalogue entries referring to specific older AI model products (for example, older ChatGPT or Bard-branded learning pages, if still surfaced by a particular catalogue view) must be checked for current availability and educational value before inclusion. Do not interpret a historical catalogue listing as a recommendation to teach obsolete products as current tools.

### Duplicate/version handling
Bootstrap 3/4/5 and AngularJS/Angular are separate catalogue entries, but our eventual curriculum should explain version relationships and migration context. Avoid duplicate lessons where one canonical concept with version-specific notes is clearer.

## 6. Limitations

This is a verified category-level baseline based on the official catalogue surfaces visible at the inventory date, not a claim that every tutorial chapter, subtopic, reference entry, or exercise has already been enumerated. W3Schools can add, remove, rename, or reorganize catalogue entries. Recheck the official catalogue during B3/B4 and before curriculum release. Some broad entries may contain multiple distinct technologies; B2 and B3 will normalize and expand them.
