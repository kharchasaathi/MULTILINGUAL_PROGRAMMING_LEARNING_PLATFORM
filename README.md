# Multilingual Programming Learning Platform

A professional programming education platform for Telugu, English, Malayalam, Kannada, Tamil, and Hindi.

## Product direction
- Responsive website first, followed by PWA and Android; iOS is a future platform.
- Learning paths from absolute beginner to professional.
- Audience: school and college students, job seekers, working professionals, self-learners, and career switchers.
- Original lessons, examples, exercises, projects, assessments, progress tracking, and AI-assisted tutoring.
- Initially free. Future premium/institutional models and prices are not yet decided.

## Curriculum and content
Use W3Schools public topic taxonomy as a coverage reference. Create original explanations, code samples, diagrams, exercises, quizzes, and projects; do not copy protected lesson text, examples, diagrams, or distinctive layouts.

## Engineering principles
Security by design, least privilege, documented contracts, automated quality gates, accessible responsive UX, and no untrusted code execution on the main application server.
