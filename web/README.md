# CodeSaathi — Web v1

Static HTML, CSS and JavaScript learning website.

## Current implementation
- Responsive landing page and Telugu/English interface switch
- Starter lessons for HTML, CSS and JavaScript
- Browser code editor with sandboxed iframe preview
- Local browser progress tracking via localStorage
- No frontend framework or build step

## Run locally
Open `index.html` in a modern browser, or serve this folder with any static HTTP server.

## Release boundaries
- Lessons are starter content, not a complete curriculum.
- Progress is local to this browser/device and is not synced to an account.
- No payment collection, ₹1 checkout, paid-content enforcement or user authentication is implemented.
- The editor is an educational preview, not a secure production sandbox for arbitrary untrusted code.

## Hosting
Firebase Hosting is configured in the repository root. See `DEPLOYMENT.md`. Do not change GoDaddy DNS until Firebase displays the exact domain-verification and routing records.
